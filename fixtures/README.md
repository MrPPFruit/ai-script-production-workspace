# Fixture 状态

`default-script-*` 现为《雷雨》·面试 Demo 导入版本（第四幕）的本地演示数据。

- V1 保存来源页“第四幕4”的终局连续片段全文，并划分 3 个处理单元。
- V2 保持连续正文逐字不变，仅把终局处理单元拆为 3A/3B，共 4 个处理单元。
- `default-script.txt` 是 UTF-8 本地导入样本：除标准文件结尾换行外，正文与 JSON 的 `version-v1.fullText` 逐字一致。它只代表第四幕本次导入的终局连续片段，不是第四幕全文或整部原作。
- JSON 包含可核验的 `fullTextRange`、逐字 evidence、待审建议、已确认实体、未下发任务草稿和 1 个待人工处理的版本影响。
- “处理单元”不是曹禺原作场次；本样本也不是《雷雨》全剧或第四幕全文。
- 来源和私下面试 Demo 使用边界见 `SOURCE_AND_LICENSE.md`。
